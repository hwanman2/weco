# 청우해장 · 키워드 분석과 광고 운영

네이버 데이터랩 검색어 트렌드 API 로 뽑은 실제 수치를 근거로 정리했습니다.
조회 기간 **2025-08 ~ 2026-08**, 월 단위. 숫자는 조회 구간 내 최댓값을 100 으로 둔
**상대 지수**입니다(절대 검색량이 아닙니다).

|---|---:|---|

### 이 표에서 나온 결론 세 가지

**① "대구해장국"으로 사이트를 짜면 안 됩니다.**
가게 이름이 해장이라 자연스럽게 잡게 되는 키워드지만, 일반 "해장국"(78.0) 대비
**74분의 1** 밖에 안 됩니다. 1등을 해도 들어오는 사람이 얼마 없습니다.

**② 갈비탕이 숨은 금맥입니다.**
「갈비탕」 묶음이 65.3 으로 「대구맛집」(69.4)에 거의 맞먹습니다. 그런데 청우해장의
실제 대표 메뉴가 **갈비 산더미 맑은 갈비탕**이고, 블로그 후기도 갈비탕 이야기가
제일 많습니다. 지금까지 이 검색량을 거의 못 받고 있었습니다.
→ 홈페이지 제목·설명·본문에 갈비탕을 해장국과 같은 비중으로 넣었습니다.

**③ 관광 키워드는 볼륨이 아니라 "위치"로 먹는 겁니다.**
근대골목(1.6)·약령시(14.4)는 지수가 낮습니다. 하지만 이 검색을 하는 사람은
**지금 대구에 있고, 도보 5분 거리에 있고, 곧 밥을 먹습니다.** 전환율이 다릅니다.
→ 홈페이지에 「약전골목 350년 역사 + 근대골목투어 코스 + 도보 몇 분」 섹션을
   따로 만들고, 구조화 데이터(`ItemList` / `TouristAttraction`)로도 넣었습니다.

### 계절성

「해장국」은 **10월에 최고점(100)**, 8월에 저점(49.6)입니다. 「갈비탕」도 10월·1월이
높습니다. 추워질 때 검색이 몰립니다.
→ **광고 예산은 9월 하순부터 올리고 2월까지 유지**, 한여름은 줄이고
   그 시기엔 평양냉면·고기냉국수로 갈아타는 것이 맞습니다.

| 검색 의도 | 어디에 넣었나 |
|---|---|
| 갈비탕 / 맑은갈비탕 | 제목·메타설명·메뉴 첫 화면·구조화 데이터 `MenuItem` |

| 대구중구맛집 / 반월당 맛집 | 메타 키워드·「오시는 길」 본문 |
| 약령시 / 약전골목 / 근대골목투어 | 「골목」 섹션 전체 + `TouristAttraction` 구조화 데이터 |
| 대구여행 / 대구 가볼만한곳 | 「걸어서 닿는 곳」 도보 코스 목록 |

`FAQPage`(자주 묻는 질문 7개), `BreadcrumbList`, `ItemList`(주변 관광지),
`WebPage` 다섯 종류가 언어마다 들어갑니다. 구글 리치 결과 테스트로 확인하세요.

## 3. 전환 설계

홈페이지에서 「매출로 이어지는 행동」을 네 가지로 정의하고, 버튼마다 심어 두었습니다.
버튼을 누르면 **메타 · 구글광고 · GA4 · 카카오에 동시에** 같은 사건이 전달됩니다.

| 내부 이름 | 손님 행동 | 메타 표준 이벤트 | GA4 | 기본 가치 |
|---|---|---|---|---:|
| `call` | 전화 걸기 | `Contact` | `click_to_call` | 30,000원 |
| `directions` | 길찾기 누르기 | `FindLocation` | `get_directions` | 25,000원 |
| `reserve` | 네이버 예약 누르기 | `Schedule` | `reservation_intent` | 40,000원 |
| `menu` | 메뉴 열람 | `ViewContent` | `view_menu` | — |

보조 신호로 `gallery`(사진 확대), `copyaddress`(주소 복사),
`language`(언어 전환), `engaged`(75% 스크롤 / 30초 체류)도 보냅니다.

**가치 금액은 임의값입니다.** 객단가와 실제 방문 전환율을 알면 조정하세요.
계산식: `전화 1건 가치 = 평균 객단가 × 전화→방문 전환율 × 평균 동반 인원`.
예) 객단가 13,000원 × 방문율 60% × 2.5명 ≈ 19,500원.
`assets/tracking.js` 의 `EVENTS` 표에서 `value` 를 고치면 됩니다.

### 왜 이렇게 하나
전화·길찾기를 전환으로 잡아 두면 광고 플랫폼이 **"클릭 많이 나는 사람"이 아니라
"전화 거는 사람"을 찾아서 노출**합니다. 이게 광고 고도화의 실체입니다.
이걸 안 하면 아무리 예산을 써도 알고리즘은 정답을 모릅니다.

## 4. 설치 순서

### 메타 (페이스북·인스타그램)
1. business.facebook.com → 이벤트 관리자 → 데이터 소스 → 픽셀 만들기
2. 픽셀 ID 를 `assets/config.js` 의 `metaPixelId` 에 붙여넣기
3. 이벤트 관리자에서 `Contact` / `FindLocation` / `Schedule` 을
   **맞춤 전환**으로 등록
4. Meta Pixel Helper 확장으로 실제 발사 확인
5. (권장) 나중에 **전환 API**를 붙이면 아이폰 iOS 추적 차단분까지 회수됩니다.
   지금 구조에서는 서버가 없어 브라우저 픽셀만 붙어 있습니다.

### 구글 광고
1. ads.google.com → 도구 → 전환 → 새 전환 액션 → 웹사이트
2. 「전화」 「길찾기」 「예약」 세 개를 각각 만들기
3. 각 전환의 태그가 `AW-1234567890/AbCdEfGhIj` 형태로 나옵니다.
   슬래시 앞은 `googleAdsId`, **슬래시 뒤 라벨만** `googleAdsLabels` 에 넣으세요.
4. GA4 도 만들어 `ga4Id` 에 넣고, 구글 광고와 계정 연결

### 동의(개인정보) 처리
외국인 손님이 오는 사이트라 EU·영국·스위스 접속자는 **구글 Consent Mode v2**
기준으로 동의 전까지 광고 쿠키를 막도록 기본값을 넣었습니다
(`assets/config.js` 의 `consentRegions`). 한국 등 그 외 지역은 기본 허용입니다.
유럽 대상 광고를 본격적으로 돌린다면 동의 배너를 추가로 붙여야 합니다.

## 5. 광고 캠페인 짜기

### 메타 — 3단 구조
| 캠페인 | 타겟 | 소재 |
|---|---|---|
| **① 근처 사람** | 매장 반경 3~5km, 25~64세 | 갈비탕·해장국 사진, "반월당 도보 5분" |
| **② 관광객** | 대구 방문 중 + 여행 관심사 / 언어 설정 영·일·중 | 근대골목 코스 + 매장 외관 |
| **③ 리마케팅** | `engaged`(75% 스크롤) + `menu` 조회자 中 `call` 미발생 | "오늘 저녁 자리 있습니다" |

③번이 제일 쌉니다. 홈페이지를 끝까지 본 사람은 이미 반쯤 오기로 한 사람입니다.

### 구글 — 2단 구조
| 캠페인 | 키워드 / 설정 |
|---|---|
| **검색(한국어)** | `대구 갈비탕`, `반월당 맛집`, `약전골목 맛집`, `대구 중구 한식`, `동성로 해장국` — ★ `대구해장국` 은 볼륨이 없어 주력에서 뺍니다 |
| **검색(외국어)** | `daegu restaurant`, `대구 韓国料理`, `大邱 美食`, `大邱 美食推薦`(대만) — 각 언어 페이지를 랜딩으로 |
| **PMax / 지역** | 위치 반경 5km + 구글 비즈니스 프로필 연결, 「매장 방문」 목표 |

**대만 손님**은 구글 검색을 씁니다(네이버·바이두 아님).
번체 페이지(`tw.html`)를 랜딩으로 잡고 `大邱 必吃`, `大邱 美食推薦`,

합니다 — 대만 사람에게 간체 페이지를 보여 주면 이탈합니다.

## 6. 상위노출 — 네이버

광고보다 이게 먼저입니다. 대구 손님은 네이버에서 찾습니다.

**① 스마트플레이스 (가장 중요)**
- 대표 사진을 **음식 사진**으로. 지금 매장 사진밖에 없습니다.
  갈비탕 한 그릇을 위에서 찍은 사진 한 장이 광고 한 달치보다 셉니다.
- 「웹사이트」 칸에 홈페이지 주소 등록 (지금 비어 있다면 꼭)
- 메뉴·가격·영업시간·브레이크타임을 홈페이지와 **똑같이** 맞추기.
  네이버·구글은 여러 출처의 정보가 일치할 때 신뢰도를 올립니다.
- 예약 기능을 켜면 홈페이지의 「네이버 예약」 버튼도 자동으로 살아납니다
  (`src/store.mjs` 의 `naverBookingUrl`).

**② 리뷰**
매장에 이미 리뷰 이벤트 안내가 붙어 있더군요(군만두·잔술 제공). 좋습니다.
여기에 하나만 더하면 좋겠습니다 — 손님에게 **"갈비탕"이라는 단어를 리뷰에
쓰도록 유도**하세요. 영수증 리뷰의 단어가 검색 노출에 그대로 반영됩니다.

**③ 블로그**
공식 블로그(blog.naver.com/zzyy004)가 이미 있습니다. 글마다 홈페이지 링크를
넣어 주세요. 주제는 검색량 순서대로:
`대구 갈비탕` → `반월당 맛집` → `약전골목 맛집` → `근대골목투어 코스`.

**④ 서치어드바이저**
`README.md` 5번 항목대로 등록 + 사이트맵 제출.
