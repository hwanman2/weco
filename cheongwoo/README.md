# 청우해장 홈페이지

대구 중구 남성로 11 · 한식당 청우해장의 다국어 홈페이지입니다.
GitHub Pages 로 그대로 서비스됩니다 — 별도 서버도, 도메인 구매도 필요 없습니다.

**주소** https://hwanman2.github.io/weco/cheongwoo/

| 언어 | 파일 | 대상 |
|---|---|---|
| 한국어 | `index.html` | 국내 손님 · 네이버 검색 |
| English | `en.html` | 영어권 관광객 |
| 日本語 | `ja.html` | 일본 관광객 |
| 简体中文 | `zh.html` | 중국 본토 |
| 繁體中文 | `tw.html` | **대만 · 홍콩** |

---

## 1. 내용을 고치는 방법

HTML 을 직접 고치지 마세요. `src/` 안의 데이터 파일을 고치고 다시 빌드하면
다섯 개 언어가 한 번에 맞춰집니다.

```bash
cd cheongwoo
node build.mjs        # Node 18 이상이면 그대로 실행됩니다. 설치할 패키지 없음.
```

| 무엇을 바꾸려면 | 어느 파일을 |
|---|---|
| 전화번호 · 주소 · 영업시간 · 좌표 · 네이버 예약 링크 | `src/store.mjs` |
| 메뉴 이름 · 설명 · 가격 | `src/store.mjs`(가격) + `src/i18n.mjs`(이름·설명) |
| 한국어/영어/일본어/중국어 문안 | `src/i18n.mjs` |
| 대만(번체) 문안 | `src/i18n.tw.mjs` |
| 약전골목·근대골목 이야기, 주변 관광지 | `src/hood.mjs` |
| 광고 픽셀 ID | `assets/config.js` (빌드 불필요) |
| 디자인 | `assets/site.css` (빌드 불필요) |

빌드하면 `sitemap.xml` 도 같이 다시 만들어집니다.

## 2. 지금 바로 채워야 할 값

`src/store.mjs` 에 비어 있는 항목입니다. **비어 있어도 사이트는 정상 동작합니다** —
채우면 링크가 「검색 결과」가 아니라 「그 가게 페이지」로 바로 꽂힙니다.

```js
naverPlaceId:    '',   // 네이버 플레이스 ID
googleCid:       '',   // 구글 비즈니스 프로필 CID
naverBookingUrl: '',   // 네이버 예약 URL → 「네이버 예약」 버튼이 생깁니다
```

**네이버 플레이스 ID 찾는 법**
네이버지도에서 「한식당 청우해장」을 검색해 가게를 클릭하면 주소창이
`map.naver.com/p/entry/place/`**`1234567890`** 형태가 됩니다. 굵은 숫자만 넣으세요.

**구글 CID 찾는 법**
구글지도에서 가게를 열고 「공유 → 링크 복사」 하면 `maps.app.goo.gl/...` 가 나옵니다.
그 링크를 브라우저에서 열면 주소창에 `?cid=`**`1234567890`** 이 보입니다.
그 숫자입니다. (구글 비즈니스 프로필이 아직 없으면 먼저 등록하세요 — 무료입니다.)

> 이 두 값은 제가 대신 찾으려 했지만, 작업 환경의 네트워크가 네이버지도와
> 구글지도 접속을 막고 있어 확인하지 못했습니다. 사장님 폰으로 30초면 됩니다.

**이미 넣어 둔 값**
- 카카오맵 플레이스 ID `983201124` (확인 완료)
- 네이버 블로그 `blog.naver.com/zzyy004` (공식 블로그로 확인)
- 인스타그램 `instagram.com/chungwoo.official` — 검색으로 찾은 계정입니다.
  **공식 계정이 맞는지 한 번만 확인해 주세요.** 아니면 `src/store.mjs` 에서 지우면 됩니다.

## 3. 사진 — 특히 메인 사진

지금 홈페이지 첫 화면은 **매장 외관 사진**입니다. 위코컴퍼니가 시공·촬영한
매장 사진 10장(`../images/cheongwoo-01.jpg` ~ `-10.jpg`)만 있고
**음식 사진이 하나도 없기 때문**입니다.

식당 홈페이지 첫 화면은 음식 사진이 가장 강합니다. 사진만 구하면 **두 줄**로 바뀝니다.

### 음식 사진 넣는 법

1. 사진을 `weco/images/` 에 넣습니다 — 예: `cheongwoo-food-01.jpg`
   (가로 1600px 이상, 1장당 500KB 이하 권장)
2. `src/store.mjs` 의 `hero` 를 고칩니다:
   ```js
   export const hero = {
     src: 'images/cheongwoo-food-01.jpg',
     kind: 'food',              // ← 'food' 로 두면 글씨 뒤 어둠이 왼쪽으로 쏠려
     position: 'center 55%',    //   오른쪽 음식이 안 가려집니다
     width: 1600, height: 1067,
   };
   ```
3. 메뉴별 사진도 같은 방식으로 `menu` 배열의 `img: null` 을 채웁니다.
4. `node build.mjs`

### 네이버에서 다운받아 쓰는 건 — 출처를 나눠서 봐야 합니다

**써도 되는 것**
- **스마트플레이스에 사장님이 직접 올린 업체 사진.** 가게가 저작권자입니다.
  네이버 이미지 검색에서 `ldb-phinf.pstatic.net` 로 시작하는 주소가 이것들입니다.
  실제로 「한식당 청우해장」 이름으로 등록된 사진이 여러 장 있습니다.
  스마트플레이스 관리자 화면에서 **원본을 그대로 내려받는 게 가장 깨끗합니다.**
- 공식 블로그(`blog.naver.com/zzyy004`)에 가게가 직접 올린 사진.
- 사장님 폰에 있는 원본.

**쓰면 안 되는 것**
- **손님·블로거가 쓴 후기 글의 사진.** 찍은 사람에게 저작권이 있습니다.
  가게 홈페이지는 영리 목적이라 무단 사용 시 저작권 문제가 됩니다.
  실제로 국내에서 분쟁이 자주 나는 유형입니다.
  꼭 쓰고 싶은 사진이 있으면 블로거에게 댓글로 사용 허락을 받으세요.
  (대부분 흔쾌히 허락해 주고, 그 자체가 홍보가 됩니다.)

> 제가 직접 내려받아 넣지는 못했습니다. 작업 환경의 네트워크가
> `pstatic.net`(네이버 이미지 서버) 전체를 막고 있어 접근이 안 됩니다.
> 사장님이 스마트플레이스에서 원본을 받아 주시면 제가 바로 넣겠습니다.

### 새로 찍는다면 (이게 제일 낫습니다)

메인 사진 한 장에 쓸 컷:
- **갈비탕을 위에서 45도로**, 갈비가 쌓인 게 보이게. 김이 살아 있을 때.
- **가로(landscape) 프레임**으로. 세로 사진은 첫 화면에 안 맞습니다.
- 오른쪽에 그릇, 왼쪽은 상판이 비게 — 그 빈자리에 글씨가 올라갑니다.
- 매장 창가 자연광. 조명 안 만져도 됩니다. 낮 12시 전이 제일 좋습니다.
- 매운갈비찜은 **위에서 수직으로**, 냄비 가득 찬 게 보이게 한 장 더.

폰으로 찍어도 충분합니다. 중요한 건 카메라가 아니라 각도와 빛입니다.

## 4. 광고 픽셀 붙이기

`assets/config.js` 하나만 고치면 됩니다. 값이 비어 있으면 그 플랫폼 스크립트는
아예 로드되지 않으므로, 쓰는 것만 채우면 됩니다.

```js
metaPixelId: '1234567890',          // 메타(페이스북·인스타) 픽셀
googleAdsId: 'AW-1234567890',       // 구글 광고
googleAdsLabels: { call:'AbC...', directions:'DeF...', reserve:'GhI...' },
ga4Id: 'G-XXXXXXXXXX',              // 구글 애널리틱스 4
```

자세한 전환 설계와 캠페인 운영법은 **`MARKETING.md`** 를 보세요.

### 잘 붙었는지 확인하는 법
- `config.js` 에서 `debug: true` 로 바꾸면 브라우저 콘솔에 이벤트가 찍힙니다.
- 메타: Chrome 확장 **Meta Pixel Helper**
- 구글: **Google Tag Assistant** 또는 GA4 실시간 보고서

## 5. 검색엔진 등록 (한 번만 하면 됩니다)

1. **네이버 서치어드바이저** (searchadvisor.naver.com)
   - 사이트 등록 → `https://hwanman2.github.io/weco/cheongwoo/`
   - 소유확인 코드를 받으면 `assets/config.js` 의 `naverSiteVerification` 에 넣고
     `node build.mjs` 재실행
   - 사이트맵 제출: `https://hwanman2.github.io/weco/cheongwoo/sitemap.xml`
2. **구글 서치콘솔** (search.google.com/search-console)
   - 같은 방식. 코드는 `googleSiteVerification` 에.
   - 리치 결과 테스트로 구조화 데이터 확인:
     search.google.com/test/rich-results
3. **네이버 스마트플레이스 · 구글 비즈니스 프로필**
   - 두 곳 모두 「웹사이트」 칸에 위 주소를 넣어 주세요.
     지도에서 홈페이지로 들어오는 경로가 생기고, 검색엔진이 두 정보를
     같은 가게로 묶어 인식합니다. 이게 지역 검색에서 제일 큰 한 방입니다.

## 6. 구조

```
cheongwoo/
├─ build.mjs           빌드 스크립트 (의존성 없음)
├─ src/
│  ├─ store.mjs        매장 정보 원본 — 전화·주소·시간·메뉴·좌표
│  ├─ i18n.mjs         한국어/영어/일본어/중국어 문안
│  ├─ i18n.tw.mjs      대만(번체) 문안
│  └─ hood.mjs         약전골목·근대골목 역사와 주변 관광 코스
├─ assets/
│  ├─ site.css         스타일
│  ├─ site.js          화면 동작 (외부 라이브러리 없음)
│  ├─ config.js        ★ 광고·측정 ID — 여기만 고치면 픽셀이 붙습니다
│  └─ tracking.js      메타·구글·카카오·네이버 통합 전환 추적
├─ index.html en.html ja.html zh.html tw.html    ← 생성물
└─ sitemap.xml                                    ← 생성물
```

외부 라이브러리는 **글꼴 두 개**(Pretendard, Noto Serif KR)뿐이고
자바스크립트 라이브러리는 하나도 쓰지 않습니다. 느린 모바일 회선에서도
먼저 뜨고, 라이브러리가 깨져서 사이트가 죽는 일도 없습니다.

## 7. 지도에 대해

지도 임베드는 **OpenStreetMap**(오픈소스, API 키 불필요)을 씁니다.
어느 나라에서 접속해도 뜨고, 키 만료로 지도가 깨질 일이 없습니다.

손님이 실제로 누르는 **길찾기 버튼은 네이버지도 · 카카오맵 · 구글지도**
세 곳으로 각각 직행합니다. 한국 손님은 네이버/카카오, 외국인은 구글을 씁니다.

> 카카오맵을 홈페이지 안에 직접 띄우고 싶다면 developers.kakao.com 에서
> JavaScript 키를 발급받고 `hwanman2.github.io` 를 플랫폼 도메인으로 등록한 뒤
> `assets/site.js` 의 지도 로딩부를 카카오 SDK 로 교체하면 됩니다.
> 다만 지금 방식이 관리가 편하고 고장이 없습니다.

## 8. 확인이 필요한 정보

아래는 출처마다 값이 다르거나 검증이 덜 된 항목입니다.
**사장님께 한 번씩 확인받고 `src/store.mjs` 에서 고쳐 주세요.**

### 영업시간 — 출처가 엇갈립니다
| 출처 | 내용 |
|---|---|
| 블로그 후기 (2026-08-15) | 11:00–22:00 · 브레이크 15:00–17:00 · 라스트오더 21:00 |
| 스레드 게시물 | 11:00–**23:00** · 라스트오더 **22:00** |

**현재 홈페이지는 22:00 마감으로 적어 두었습니다** (더 최근·더 구체적인 출처).
`src/store.mjs` 의 `hours` 한 곳만 고치면 본문·구조화 데이터·「영업 중」 배지가
전부 같이 바뀝니다.

### 가격
| 메뉴 | 홈페이지 표기 | 근거 |
|---|---|---|
| 맑은해장국 / 얼큰해장국 / 얼큰장칼국수 | 12,000원 | 매장 벽면 메뉴 포스터 사진 |
| 청우 약전 갈비탕 | 12,000원 | 매장 벽면 포스터 |
| 매운갈비찜 | 47,000원 | 매장 벽면 포스터 |
| 아롱사태수육 · 소꼬리찜 · 평양냉면 | **가격 문의** | 확인된 값 없음 |

참고로 외부 게시물에는 **아롱사태수육(소) 17,000원, 맑은해장국 9,700원**이라는
값도 있었습니다. 벽면 포스터(12,000원)와 다른 걸 보면 **예전 가격일 가능성이
큽니다.** 틀린 가격은 계산대에서 분쟁이 되기 때문에, 확인되지 않은 메뉴는
일부러 「가격 문의」로 두었습니다. 정확한 가격표를 주시면 바로 넣겠습니다.

### 그 밖에
- **정기 휴무일**: 확인된 정보가 없어 연중무휴로 적었습니다.
  정기 휴무가 있으면 꼭 알려 주세요. 헛걸음한 손님은 리뷰로 돌아옵니다.
- **주차**: 「전용 주차장 없음, 인근 공영주차장」으로 적었습니다.
  가게 앞에 1~2대 댈 수 있다는 제보가 있는데, 맞다면 문구를 고치겠습니다.
- **한자 표기**: 간판 사진 두 장(외관·출입문)을 확대해 확인한 결과
  **靑友解酲**(푸를 靑)입니다. 홈페이지도 그렇게 적었습니다.
  다만 인스타그램 계정 표시명에는 **淸友解酲**(맑을 淸)로 되어 있는 듯합니다.
  어느 쪽이 맞는지 알려 주시면 통일하겠습니다.
